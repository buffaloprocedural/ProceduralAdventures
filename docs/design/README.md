# Design notes

Notes from The Buffalo, New York Procedural Amusements Coding Society.

* `Creature_Roster_40_Divas_Shy_Ones.docx`: the creature roster (12 types in four rings of three, the creatures,
  their attacks and more). `creature_roster_notes.txt` is a plain-text copy for searching. `src/game/roster.js`
  is the roster as it is in the game.
* `FRIENDSHIP.md`: how wild creatures become your friends (approaches, hearts, the care table).
* `STORY_SYSTEM_PLAN.md` and `story_ideas.txt`: how stories are dealt from four decks of cards.
