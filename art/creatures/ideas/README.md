# Twenty new creature ideas

Twelve creatures were retired in October 2026, leaving 28. These twenty new ideas are candidates for the empty
places - front views only, for now (`<name>.svg`, 32x32). They lean toward the types that lost the most: STONE,
BREEZE, CHROME and BLIGHT are down to one creature each.

Pick the ones you like (any number; twelve brings the roster back to forty) and they get the rest of a battle set
(back view, party icons), stats, three attacks and an ALMANAC entry. Drawn with the same vector rig as the options
(`tools/creature_designs/ideas.py`; `python3 tools/build_creature_options.py --ideas gallery.png`).
